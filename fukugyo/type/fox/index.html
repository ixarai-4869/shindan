キツネの「コン」

売るタイプ（商売人）を深掘り

見つける目が、そのまま利益に。

いいものを見つける目と、決めたら動ける行動力を持つ人のためのタイプです。お得な情報や掘り出し物に敏感なタイプ。フリマやせどりなど、仕入れて売る形は結果が早く、数字で見えます。

診断結果の画面にある「あるある」「取扱説明書」などは省き、このページでは場面別のふるまい、始めてからの時系列、称号ごとの使い方、ロードマップを詳しく解説します。

売るタイプの強みと弱み

  • 売れるものを見抜く目
  • 素早い判断と行動力
  • 数字で結果を追える冷静さ

つまずきやすい点：勢いで仕入れすぎること。最初は「売れてから仕入れる」ルールで。

場面別：売るタイプのふるまい

会議・打ち合わせで
費用対効果の話になると目が光る。「それ、いくらで回収できる？」と聞ける人です。
締め切り前
判断と手配が速く、慌てても最短ルートを見つける。ただし確認を飛ばして小さなミスが出ることも。
お金の使い方
セールやポイントを使いこなし、買ったものを転売できるかも自然と考えている。衝動買いにだけ注意。
失敗したあと
「いくら損したか」を数字にすると落ち着く。数字にした失敗は、次の判断材料に変わります。

副業を始めてからの時系列：起きること・抜け方

始めて2週間目
起きること：商品を探し回って、どれも決め切れずに仕入れが進まない。
抜け方：最初は小さく1つだけ仕入れる、または自分の不用品を売る。実際に売れる体験が先です。
1か月目の壁
起きること：利益が思ったより残らない。送料・手数料・梱包を足すと赤字に近い。
抜け方：1件ごとに利益を記録する。数字を見れば、売るべき商品の条件が分かります。
3か月目の分かれ道
起きること：売れるジャンルを広げすぎて、在庫や管理が散らかる。
抜け方：得意な1〜2ジャンルに絞る。在庫を持たない形（受注後に手配）も検討します。

収入が伸びる型：週5時間の配分例

  • 商品リサーチ・価格調べ1.5時間
  • 出品・問い合わせの対応2時間
  • 発送・記録・振り返り1.5時間

最初は自分の不用品で十分です。出品用に写真を撮れるスマホと、利益を記録する表があれば始められます。

最初の30日は「出品数」「売れた数」「1件あたりの利益」を見ます。配分は一般的な目安で、収益を保証するものではありません。

称号4つの使い方

診断では、2番目に強い素質によって称号が変わります。

物知りな商売人（書くの素質）
買う前にしっかり調べて動く慎重派の商売人です。相場や需要を調べてから仕入れるので、失敗しにくいのが強みです。動き出しが遅くなる傾向があるので、最初の1件を小さく決めましょう。
愛されキャラの商売人（話す・見せるの素質）
商品を魅力的に紹介するのがうまいタイプです。写真や説明文で売れ行きが変わるので、見せ方を磨くほど伸びます。値引きに流されないよう、最低価格を先に決めておきましょう。
器用な商売人（作るの素質）
商品のパッケージや見せ方にもこだわれる商売人です。ハンドメイドの販売や、梱包が丁寧で選ばれる出品者に向いています。見た目に時間をかけすぎないよう、作業時間の上限を決めましょう。
堅実な商売人（こなすの素質）
仕入れは勢いがあるのに、記録と管理をきちんとできるタイプです。帳簿や在庫管理を続けられるので、長く安定して続けられます。確定申告の準備も早めにすると安心です。

はじめの一歩のコツ

  • まずは家の不用品で、出品から発送までの流れを体で覚えます
  • 「売れてから次を仕入れる」ルールで、在庫を抱えすぎないこと
  • 中古品を継続して仕入れるなら古物商許可を確認しましょう

Lv1〜Lv4ロードマップ

  1. Lv1 最初の一歩やること：不用品や小さな商品を1つ出品し、売れるまでの流れを経験する。変わること：「売った人」になる。つまずき所：送料・手数料の計算が合わない
  2. Lv2 初収入やること：1件売れて、利益を記録する。変わること：利益の出る条件が見えてくる。つまずき所：赤字の商品を続けてしまう
  3. Lv3 月1万円を目指す段階やること：得意ジャンルを決めて、安定して出品・販売する。変わること：仕入れ・価格の判断が速くなる。つまずき所：在庫や管理が増える
  4. Lv4 月5万円を目指す段階やること：販路を増やす、または受注型の仕組みを作る。変わること：運営が仕組みになる。つまずき所：税金や法令の確認が必要になる

金額は目標の目安で、達成や収益を保証するものではありません。

相棒と組むなら

最高の相棒は「作る」タイプ（ビーバーのポコ）。売る人が需要と値付けを見抜き、作る人が商品を生みます。分担は「リサーチ・価格・販売＝売るタイプ」「制作・品質＝作るタイプ」が基本です。

最高の相棒：ビーバーのポコ（作るタイプ）
作るタイプの商品を売れば、仕入れなしで回せます。 真逆のタイプ：フクロウのフミ（書くタイプ）
じっくり積み上げる書くタイプとは、時間感覚が逆。

よくある疑問

仕入れが必要ない売る副業はありますか？
あります。自分の不用品の出品、受注してから手配する形、他人のサービスを紹介する形など、在庫を持たない方法も選べます。
転売は違法になりませんか？
チケットなど転売が禁止されているものがあります。法令・サイトの規約・古物営業の許可が必要なケースを必ず確認してください。迷うものは扱わないのが安全です。
利益はどのくらい残りますか？
商品と手数料次第で大きく変わります。まず1件ごとに利益を記録し、残る商品だけ続けるのが現実的です。
在庫を抱えるのが怖いです。
最初は少量、売れ筋だけを仕入れます。「売れてから仕入れる」型から始めると、在庫のリスクをほとんど抑えられます。
