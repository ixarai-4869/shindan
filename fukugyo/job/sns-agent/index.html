最初の30日プラン

  1. 1日目クラウドソーシングに登録し、SNS運用の案件を10件読む
    クラウドソーシングに無料登録 →
  2. 3日目自分のアカウントで、投稿の作り方の見本を3つ作る
  3. 7日目身近なお店に「無料で1か月お手伝い」を提案してみる
  4. 14日目代行した投稿の反応を数字でまとめ、実績にする
  5. 21日目実績を添えて、有料の案件に3件応募する
  6. 30日目月額いくらで何投稿するか、自分の料金表を作る
