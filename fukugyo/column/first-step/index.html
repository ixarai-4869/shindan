副業は何から始める？未経験でも迷わない3ステップ

副業選びで迷う人の多くは、「稼げる副業」から探し始めています。順番を逆にして、自分の条件と向き不向きから決めると、続く副業が見つかりやすくなります。

ステップ1：使える時間とお金を書き出す

最初に決めるのは「何をやるか」ではなく「どれだけ使えるか」です。平日と休日に分けて、副業に回せる時間を正直に書き出しましょう。

  • 平日は1日30分か、1時間か
  • 休日は何時間使えるか
  • 最初にかけてもいいお金はいくらまでか（0円でもかまいません）
  • 顔や声を出すのは平気か

週2〜3時間しか取れないなら、時間の融通がきく作業型や、空き時間に出品できるフリマ販売が現実的です。週5時間以上取れるなら、ライターや代行系も選べます。

ステップ2：向いている「種類」を選ぶ

副業は大きく「書く」「話す・見せる」「作る」「売る」「こなす」の5種類に分けられます。得意なことに近い種類を選ぶと、最初の壁を越えやすくなります。

  • 調べてまとめるのが好き → 書く（Webライター、ブログ）
  • 人と話すのが好き → 話す・見せる（SNS発信、配信）
  • 手を動かすのが好き → 作る（ハンドメイド、デザイン）
  • 値段や相場が気になる → 売る（フリマ、せどり）
  • 決まった作業をきっちりやりたい → こなす（データ入力、オンライン秘書）

どれに当てはまるか迷ったら、診断で確かめるのが早道です。11問・約2分で、タイプと今の条件で始められる副業がわかります。

ステップ3：最初の30日は「1件目」だけを目標にする

最初の1か月で大きく稼ごうとすると、たいてい続きません。目標は「最初の1件」です。1件売れる、1件納品できる、という経験があると、2件目からは迷いが減ります。

  1. 1週目：登録とプロフィール作り
  2. 2週目：小さな案件・出品を1つ
  3. 3〜4週目：1件目を終わらせて、かかった時間を記録する

1件目までの期間の目安は、フリマ販売で1週間前後、データ入力で2週間前後、Webライターで2〜4週間です。
